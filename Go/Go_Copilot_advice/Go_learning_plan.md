# Goの学習順まとめ

## 1. 初心者
- 変数・型・if・for
- 関数
- slice / map / struct
- error handling
- package と import

## 2. 中級者
- 関数分割
- JSON / file I/O
- error設計
- 標準ライブラリ活用
- 構造体設計

## 3. 上級者
- goroutine / channel
- context / mutex
- HTTP / DB
- testing / benchmark
- 実務設計

## 4. これが一番大事
- 最初は「文法」より「考え方」を覚える
- Goは静的型・明示的エラー処理・並行処理が大事
- まずは小さなプログラムを作って、動かして、修正する

## 5. 初心者におすすめの練習題材
- じゃんけん
- 電卓
- 点数集計
- 誕生日判定
- 文字列検索
- ToDoリスト

## 6. 目安
- 1〜2週間: 基本文法
- 1か月: 関数・slice・map・error
- 2か月: package設計・JSON・ファイル操作
- その後: 並行処理と HTTP / DB

## 7. 実務に直結するコツ
- まずは小さなCLIを作る
- 1つの機能を分割して書く
- gofmt と go test を習慣にする
- エラーを見逃さない
