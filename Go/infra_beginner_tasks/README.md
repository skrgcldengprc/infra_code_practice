# インフラ向け Go 初心者問題集

このディレクトリは、シェルスクリプトが少し使える初心者が、Go の基礎を実際のコーディングで理解するための問題集です。

## 目標
- Go の基本構文を理解する
- 変数、条件分岐、ループ、関数、構造体を使えるようにする
- インフラ業務に関連する処理（ファイル読み込み、環境変数、ディレクトリ一覧、ログ確認）を Go で書けるようにする
- `go run` で実行できる最小コードを作る

## 進め方
1. 各ファイルを順番に開く
2. 問題の要件を確認する
3. `go run <ファイル名>` で動作確認する
4. 必要に応じて 1 問ずつ自分で実装する
5. できたら、コードを自分の言葉で説明できるようにする

## 問題一覧
1. 01_variable_output.go - 変数と出力
2. 02_if_comparison.go - 条件分岐
3. 03_for_loop.go - 繰り返し処理
4. 04_array_slice.go - 配列とスライス
5. 05_function.go - 関数の作成
6. 06_environment_variable.go - 環境変数の利用
7. 07_file_read.go - ファイルの読み込み
8. 08_directory_listing.go - ディレクトリの一覧表示
9. 09_map_struct.go - MAP と構造体
10. 10_server_check.go - サーバー状態の簡単なチェック

## 実行例
```bash
go run 01_variable_output.go
```

## ルール
- 1 問ずつ取り組む
- まずは自分で考えてから検索する
- エラーが出たら、エラーメッセージを確認して修正する
- 最初は「動く」を優先し、少しずつ「読みやすく」「管理しやすく」を意識する

## 学習のコツ
- シェルスクリプトでできることを Go でも書いてみる
- `fmt.Println` で中間結果を出して確認する
- ループや条件分岐は、1 つの小さな処理から始める
- 関数に分けるとコードが見やすくなる

この問題集は、インフラ業務で使う「小さな自動化」を Go で書く感覚を養うことを目的にしています。
